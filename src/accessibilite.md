## Notre engagement

L'accès à l'information sur la biodiversité doit être ouvert à toutes et à tous. Le site est
conçu pour respecter les bonnes pratiques d'accessibilité numérique :

- **structure sémantique** claire (titres hiérarchisés, repères de navigation, fils d'Ariane) ;
- **navigation au clavier** possible sur l'ensemble des pages, avec un lien d'évitement ;
- **contrastes** de couleurs conformes aux recommandations pour le texte et les éléments d'interface ;
- **textes alternatifs** pour les images porteuses d'information ;
- **contenus lisibles** sur mobile, tablette et ordinateur (mise en page adaptative) ;
- respect des préférences système, notamment la **réduction des animations**.

## Technologies utilisées

Le site est un ensemble de pages HTML statiques, enrichies de CSS et d'un peu de JavaScript.
Les fonctionnalités principales (navigation, lecture des fiches) restent utilisables même si
le JavaScript est désactivé.

## Amélioration continue

L'accessibilité est un travail permanent. Si vous rencontrez une difficulté pour accéder à un
contenu, signalez-la à <a href="mailto:allofrelons@gmail.com">allofrelons@gmail.com</a> :
nous nous efforçons de corriger les problèmes signalés et de proposer une alternative d'accès à l'information.
